# 1.17.2

This Multipass 1.17.2 patch release resolves two issues: one that prevented instances from starting properly after an upgrade, and another that could cause streamed exec outputs to stall.

## Bug fixes

 - Fixes an issue caused by hard-coded paths in the persistent instance information that prevented snap based instances from starting correctly after an upgrade from 1.17.0 to 1.17.1. ([#5559](https://github.com/canonical/multipass/pull/5559))
 - Fixes a regression that prevents streamed `exec` output from stalling. ([#5485](https://github.com/canonical/multipass/pull/5485))
