# 1.14.0

These release notes cover new features and changes in Multipass 1.14.0.

Multipass 1.14.0 introduces an early version of the Multipass GUI, a new
Flutter-based desktop application for managing instances. This release also
adds support for bridged networking, makes snapshots preserve an instance's
identity and network configuration across restore, and tightens file
ownership rules in mounts.

## Breaking changes

### Mounts

- File operations in SSHFS mounts are now restricted to files that have a
  configured host-to-guest ID mapping; files without a mapping are owned by
  `nobody:nogroup` in the instance
  ([#3323](https://github.com/canonical/multipass/pull/3323),
  [#3350](https://github.com/canonical/multipass/pull/3350))
- Only one-to-one ID mappings are allowed when mounting
  ([#3349](https://github.com/canonical/multipass/pull/3349))

## Features

### Multipass GUI

- Introduce the Multipass GUI, a new desktop application to create, manage,
  and interact with instances
  ([#3504](https://github.com/canonical/multipass/pull/3504))
- Build the GUI from bundled Flutter and Dart submodules, removing the need
  for a specific Flutter version on the host
  ([#3538](https://github.com/canonical/multipass/pull/3538))

### Bridged networking

- Add support for bridged network interfaces, enabled per instance with
  `multipass set local.<instance>.bridged=true`
  ([#3195](https://github.com/canonical/multipass/pull/3195),
  [#3193](https://github.com/canonical/multipass/pull/3193))
- Ask for authorization before creating a bridge that may disrupt the host's
  networking ([#3395](https://github.com/canonical/multipass/pull/3395))
- Configure new bridged interfaces through cloud-init, applied at first boot
  ([#3238](https://github.com/canonical/multipass/pull/3238),
  [#3423](https://github.com/canonical/multipass/pull/3423),
  [#3429](https://github.com/canonical/multipass/pull/3429))
- Add bridged interfaces on macOS with the QEMU driver
  ([#3266](https://github.com/canonical/multipass/pull/3266))
- Refuse interfaces the backend cannot provide, and limit instances to a
  single bridge ([#3371](https://github.com/canonical/multipass/pull/3371),
  [#3493](https://github.com/canonical/multipass/pull/3493))

### Snapshots

- Snapshots now track the instance ID and extra network interfaces, so
  restoring a snapshot preserves the instance's identity and network
  configuration ([#3446](https://github.com/canonical/multipass/pull/3446),
  [#3404](https://github.com/canonical/multipass/pull/3404),
  [#3433](https://github.com/canonical/multipass/pull/3433))
- Correctly restore snapshots taken with older Multipass versions
  ([#3439](https://github.com/canonical/multipass/pull/3439),
  [#3477](https://github.com/canonical/multipass/pull/3477))

### Other features

- Add a `--force` argument to the `stop` command to power off unresponsive
  instances ([#1946](https://github.com/canonical/multipass/pull/1946))
- Add support for Ubuntu Core 24 images
  ([#3540](https://github.com/canonical/multipass/pull/3540))
- Retry failed image downloads with exponential backoff
  ([#3487](https://github.com/canonical/multipass/pull/3487))
- Speed up `multipass info` on multi-core instances by parallelizing data
  collection ([#3465](https://github.com/canonical/multipass/pull/3465))
- Make the `--verbosity` option case insensitive
  ([#3474](https://github.com/canonical/multipass/pull/3474))
- Add bash completions for the `get` and `set` commands
  ([#3550](https://github.com/canonical/multipass/pull/3550))

## Bug fixes

### QEMU and boot

- Fix broken launches on the QEMU driver
  ([#3556](https://github.com/canonical/multipass/pull/3556))
- Fix an assertion failure in QEMU virtual machines
  ([#3482](https://github.com/canonical/multipass/pull/3482))
- Catch timeouts on commands executed at boot
  ([#3360](https://github.com/canonical/multipass/pull/3360))
- Sync the hardware clock with the host after resuming from suspension
  ([#3330](https://github.com/canonical/multipass/pull/3330),
  [#3396](https://github.com/canonical/multipass/pull/3396))

### Daemon and client

- Fix `multipass info` failing after a failed launch
  ([#3572](https://github.com/canonical/multipass/pull/3572))
- Avoid flipping instance state from `off` to `stopped`
  ([#3367](https://github.com/canonical/multipass/pull/3367))
- Fix issues with runtime instance information
  ([#3523](https://github.com/canonical/multipass/pull/3523))
- Shut down the gRPC server before quitting the Qt event loop
  ([#3448](https://github.com/canonical/multipass/pull/3448))
- Fetch extra IP addresses also during delayed shutdown
  ([#3428](https://github.com/canonical/multipass/pull/3428))
- Only print a message on SSH execution errors
  ([#3276](https://github.com/canonical/multipass/pull/3276))
- Reduce SSH log spam when using the GUI
  ([#3549](https://github.com/canonical/multipass/pull/3549))
- Fix the alias hint shown after launching a blueprint
  ([#3388](https://github.com/canonical/multipass/pull/3388))
- Increase the client deadline timeout
  ([#3364](https://github.com/canonical/multipass/pull/3364))

### LXD driver

- Fix instances not being reported as starting
  ([#3506](https://github.com/canonical/multipass/pull/3506))
- Check for suspend support before attempting the operation
  ([#3348](https://github.com/canonical/multipass/pull/3348))
- Throw a not-implemented error for suspend on LXD
  ([#3381](https://github.com/canonical/multipass/pull/3381))
- Fix a deadlock in the LXD driver
  ([#3585](https://github.com/canonical/multipass/pull/3585))
