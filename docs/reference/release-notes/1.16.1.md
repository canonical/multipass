# 1.16.1

These release notes cover new features and changes in Multipass 1.16.1.

Multipass 1.16.1 is a patch release. The headline fixes resolve two related
certificate problems that could break communication between the Multipass
client and daemon, along with a fix for file operations failing inside
instances that use SSHFS mounts on Windows hosts.

## Bug fixes

### Daemon and core

- Fix "root certificate not found" errors when using an external data
  directory by storing the root certificate in a consistent location that both
  the client and the daemon use
  ([#4252](https://github.com/canonical/multipass/pull/4252))
- Regenerate the gRPC server certificate when its issuer no longer matches the
  current root certificate, fixing client connections after switching between
  a snap installation and a manual installation
  ([#4226](https://github.com/canonical/multipass/pull/4226))

### Windows

- Fix file operations inside instances failing with "Operation not permitted"
  when using SSHFS mounts on Windows hosts, caused by `chown` returning an
  error on platforms without UID/GID information
  ([#4288](https://github.com/canonical/multipass/pull/4288))
