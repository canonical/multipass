# 1.16.0

Multipass 1.16.0 extends platform reach with the QEMU driver on Linux ARM64, strengthens security with standard mTLS authentication and tighter file permissions, deprecates the LXD and libvirt drivers along with blueprints, and brings a set of GUI usability improvements. This release also migrates the Multipass documentation to Read the Docs.

## Breaking Changes

- [drivers] Deprecate the LXD and libvirt drivers, with warnings on related commands ([#4024](https://github.com/canonical/multipass/pull/4024))
- [gui] Remove the LXD driver option from the GUI ([#4019](https://github.com/canonical/multipass/pull/4019))
- [gui] Remove the libvirt driver option from the GUI ([#4018](https://github.com/canonical/multipass/pull/4018))
- [cli] Deprecate blueprints, with a warning on the launch workflow ([#3988](https://github.com/canonical/multipass/pull/3988))
- [platform] Restrict Multipass cache and data directories to root-only access ([#3715](https://github.com/canonical/multipass/pull/3715))

## Features

- [qemu] Support the QEMU driver on Linux ARM64 ([#4050](https://github.com/canonical/multipass/pull/4050))
- [daemon] Use standard mTLS authentication between the client and the daemon ([#3909](https://github.com/canonical/multipass/pull/3909))
- [gui] Add a "Launch & configure next" button to the launch form ([#4029](https://github.com/canonical/multipass/pull/4029))
- [gui] Remember window size and improve default window sizes ([#3814](https://github.com/canonical/multipass/pull/3814))
- [gui] Add zoom in/out to the terminal ([#3825](https://github.com/canonical/multipass/pull/3825))
- [gui] Make instance-info fields click-to-copy ([#3878](https://github.com/canonical/multipass/pull/3878))
- [gui] Improve terminal copy/paste ([#3849](https://github.com/canonical/multipass/pull/3849))
- [gui] Confirm before closing a terminal with a running process ([#3835](https://github.com/canonical/multipass/pull/3835))
- [gui] Honour the close setting when quitting from the tray ([#4138](https://github.com/canonical/multipass/pull/4138))
- [gui] Fix launch to abort early on error instead of attempting mounts ([#3897](https://github.com/canonical/multipass/pull/3897))
- [cli] Run `sudo` commands via `exec` with `-u` to preserve the invoking user ([#3959](https://github.com/canonical/multipass/pull/3959))
- [docs] Migrate the Multipass documentation to Read the Docs ([#3921](https://github.com/canonical/multipass/pull/3921))
