# 1.16.2

These release notes cover new features and changes in Multipass 1.16.2.

Multipass 1.16.2 is a patch release. The headline fix restores LXD backend
compatibility with LXD 6 and later, alongside a fix for bridged instances
failing to start after a snap refresh. It also includes a number of
reliability fixes across all platforms and improvements to macOS build
compatibility.

## Bug fixes

### LXD backend

- Support the post-LTS LXD API, fixing the LXD backend for users with LXD 6
  and later ([#4725](https://github.com/canonical/multipass/pull/4725))
- Fix a silent chrono integer overflow in the LXD image vault when image
  timestamps are missing or invalid ([#4336](https://github.com/canonical/multipass/pull/4336))
- Include the image release in log messages when an image is skipped
  ([#4828](https://github.com/canonical/multipass/pull/4828))

### QEMU / Linux

- Fix bridged instances failing to start after a snap refresh, caused by QEMU
  picking up a `bridge_helper` binary from a different snap revision
  ([#4708](https://github.com/canonical/multipass/pull/4708))
- Fix the daemon hanging on shutdown by giving `dnsmasq` enough time to
  terminate gracefully ([#4236](https://github.com/canonical/multipass/pull/4236))
- Unblock signals in forked child processes so they respond to signals used
  for graceful shutdown ([#4237](https://github.com/canonical/multipass/pull/4237))
- Add a `-uuid` argument to QEMU so that `/sys/class/dmi/id/product_uuid` is
  present in instances, as required by some tools
  ([#4733](https://github.com/canonical/multipass/pull/4733))

### macOS

- Fix instance IP address collisions on the QEMU driver by forcing an obscure
  subnet ([#4686](https://github.com/canonical/multipass/pull/4686))
- Fix builds on the latest macOS no longer running on older macOS versions:
  OpenSSL is now built through vcpkg and the deployment target is propagated
  to all dependencies
  ([#4496](https://github.com/canonical/multipass/pull/4496),
  [#4540](https://github.com/canonical/multipass/pull/4540),
  [#4539](https://github.com/canonical/multipass/pull/4539),
  [#4547](https://github.com/canonical/multipass/pull/4547))

### Windows / Hyper-V

- Fix stale instance IP addresses after out-of-band operations such as
  `multipass restart` by invalidating the cached management IP on state
  updates ([#4207](https://github.com/canonical/multipass/pull/4207))
- Fix a potential crash when querying security descriptors that have no DACL
  ([#4735](https://github.com/canonical/multipass/pull/4735))

### Daemon and core

- Fix intermittent "Access is denied" / transactional-write failures by
  synchronizing JSON metadata writes with an interprocess file lock and retry
  with backoff ([#4294](https://github.com/canonical/multipass/pull/4294))
- Clean up a `QFutureWatcher` correctly in the daemon event loop, removing
  undefined behavior ([#4772](https://github.com/canonical/multipass/pull/4772))
- Improve the error message for invalid file URLs
  ([#4352](https://github.com/canonical/multipass/pull/4352))
