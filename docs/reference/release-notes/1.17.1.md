# 1.17.1

This Multipass 1.17.1 patch release fixes a vulnerability related to the transfer of files and an issue related to expanding `~` for target paths.

## Vulnerability & bug fixes

 - [sftp] Fix a potential vulnerability where a compromised instance could send malicious target paths to the host when executing `multipass transfer` leading to host files being changed without the user's consent. ([#5460](https://github.com/canonical/multipass/pull/5460))
 - [qemu] Expand "~" correctly for target paths ([#5417](https://github.com/canonical/multipass/pull/5417))
