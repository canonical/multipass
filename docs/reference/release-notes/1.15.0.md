# 1.15.0

These release notes cover new features and changes in Multipass 1.15.0.

Multipass 1.15.0 is a feature release. Its headline addition is the new
`multipass clone` command for duplicating instances, alongside network bridging
support for the QEMU driver on Linux, a `--force` option for `stop`, support
for Ubuntu Core 24 images, more resilient image downloads, and a round of GUI
improvements including in-app update notifications.

## Features

### Instances and daemon

- Add a new `multipass clone` command to create a copy of an existing instance,
  cloning its disk, configuration, network interfaces, and image record under a
  new (or generated) name
  ([#3264](https://github.com/canonical/multipass/pull/3264),
  [#3752](https://github.com/canonical/multipass/pull/3752))
- Add a `--force` argument to `multipass stop` to power an instance down
  immediately instead of waiting for a graceful shutdown
  ([#1946](https://github.com/canonical/multipass/pull/1946))

### Networking

- Enable network bridging for the QEMU driver on Linux, using a privileged
  bridge helper to create and attach bridged interfaces
  ([#3573](https://github.com/canonical/multipass/pull/3573))
- Fix detection of whether an instance is bridged, basing it on the configured
  preferred network and its links rather than bridge names
  ([#3545](https://github.com/canonical/multipass/pull/3545))
- Force HTTPS for all image and checksum downloads to help ensure their
  validity ([#3704](https://github.com/canonical/multipass/pull/3704))

### Images and downloads

- Add support for Ubuntu Core 24 images
  ([#3540](https://github.com/canonical/multipass/pull/3540))
- Retry failed image downloads with binary exponential backoff, making image
  fetching more resilient to transient network errors
  ([#3487](https://github.com/canonical/multipass/pull/3487))

### Mounts

- Let the daemon choose a sensible default mount target when one is not
  specified ([#3695](https://github.com/canonical/multipass/pull/3695))
- Resolve symbolic links when performing a mount, so mounting a symlink path
  mounts its target ([#3673](https://github.com/canonical/multipass/pull/3673))

### GUI

- Show an in-app and native notification when a Multipass update is available
  ([#3621](https://github.com/canonical/multipass/pull/3621),
  [#3724](https://github.com/canonical/multipass/pull/3724))
- Broad set of GUI improvements and fixes
  ([#3504](https://github.com/canonical/multipass/pull/3504))
- Guard against launching an instance with the name of a deleted instance
  ([#3725](https://github.com/canonical/multipass/pull/3725))

## Bug fixes

### Daemon and core

- Fix the `VirtualMachine::shutdown` error path affecting `multipass delete`
  ([#3625](https://github.com/canonical/multipass/pull/3625))
- Fix a crash when purge-deleting an instance while it is starting
  ([#3679](https://github.com/canonical/multipass/pull/3679))
- Fix `stop` reporting success when the instance has not actually stopped
  ([#3684](https://github.com/canonical/multipass/pull/3684))
- Fix `restart` not showing the new version
  ([#3686](https://github.com/canonical/multipass/pull/3686))
- Correct the suspended-VM condition check on force stop
  ([#3632](https://github.com/canonical/multipass/pull/3632))

### GUI

- Ensure the terminal does not render partial lines and fix Snap terminal
  scrolling to line height
  ([#3734](https://github.com/canonical/multipass/pull/3734))
